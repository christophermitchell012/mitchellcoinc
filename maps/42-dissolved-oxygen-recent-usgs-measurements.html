How to read this

Fact: each marker is a USGS stream-site dissolved-oxygen measurement returned for the preceding 48 hours. The popup preserves the time-series ID, measurement time, unit, and approval status. Limit: a point measurement does not represent an entire water body. Dissolved oxygen changes with temperature, flow, depth, time of day, biological activity, sensor placement, and other conditions. The map infers no cause, trend, ecosystem health, fish stress, impairment, swimming safety, drinking-water safety, or compliance.

Source contract

USGS modern Water Data OGC API, latest-continuous, parameter 00300. Requests are anonymous, keyless, limited to stream sites in the visible bounding box and preceding 48 hours, capped at 500 features, and protected by a 60-second client cooldown. No credential, proxy, saved measurement snapshot, or proprietary GIS service is used. Source/license notes · USGS API documentation
