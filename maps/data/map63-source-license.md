# Map 63 source and use notes

## Source contract

Map 63 presents two country-level World Development Indicators sourced from FAO AQUASTAT: **renewable internal freshwater resources per capita** (`ER.H2O.INTR.PC`) and **renewable internal freshwater resources, total** (`ER.H2O.INTR.K3`). “Internal” means renewable river flow and groundwater recharge generated by precipitation within a country. It excludes external inflows, stored non-renewable water, withdrawals, service access and water quality.

The same-origin snapshot was retrieved anonymously from the World Bank API on October 30, 2026. The API reported an October 8, 2026 update. The build retains each country's latest finite observation and excludes World Bank regional and income aggregates. Most observations are for 2022; the popup shows each value's actual year. Generalized Natural Earth polygons are reference geometry only. No value, year, boundary or missing country is inferred.

## Runtime behavior

The browser downloads one same-origin deterministically compressed JSON snapshot. It makes no authenticated or live data request. Metric and country-search controls only filter the stored observations and reference geometry.

## Limits

These are national long-term resource estimates, not live water levels, drought indicators, forecasts, basin or aquifer models, available supply, sustainable yield, withdrawals, storage, utility service, household access, drinking-water quality, affordability or safety determinations. Per-capita values combine the resource estimate with population and can change when population changes even if the underlying long-term resource estimate does not. National averages hide seasonal and subnational variation. Source estimates refer to different underlying assessment years and are less certain for small, arid and semiarid countries. Internal resources exclude water generated outside the country, so they are not total actual renewable resources. Boundaries do not imply endorsement or settled jurisdiction.
