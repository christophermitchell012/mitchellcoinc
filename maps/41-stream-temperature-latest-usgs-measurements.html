How to read this

Fact: each marker is a USGS stream-site water-temperature observation returned for the preceding 48 hours. The popup preserves observation time and approval status. Limit: a station point does not represent an entire water body. Sensors, flow, depth, shade, season, and sampling intervals differ. The map infers no trend, cause, dissolved oxygen, pathogen level, algal bloom, fish stress, recreational safety, drinking-water safety, or compliance.

Source contract

USGS modern Water Data OGC API, latest-continuous, parameter 00010. Requests are anonymous, keyless, limited to the visible bounding box and preceding 48 hours, capped at 500 features, and protected by a 60-second client cooldown. No credential, proxy, saved measurement snapshot, or proprietary GIS service is used. Source/license notes · USGS API documentation
