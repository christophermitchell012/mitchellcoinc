What is mapped

The local snapshot contains 6,102 generalized alignment features from the public USACE National Levee Database search page, retrieved October 27, 2026. Select a line to see its source feature code and open NLD.

A line or alert overlap is geographic context only. It does not establish levee ownership, accreditation, certification, inspection, structural condition, loading, protection, damage, failure, breach, closure or safety.

Limits

USACE says NLD completeness, quality and update timing vary and that it does not independently validate every submitted value. These generalized lines are not surveyed boundaries, leveed-area polygons, inundation zones, property boundaries, hydraulic models, evacuation zones or engineering drawings.
